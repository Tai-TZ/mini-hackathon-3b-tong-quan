# Mini Hackathon AI Batch 04 — Lớp 3B

Slide tổng quan lớp 3B — Mini Hackathon AI Batch 04, VinUni AI Thực Chiến.

Deck HTML tĩnh, một file duy nhất (`index.html`), 19 slide, khung 16:9 tự co theo màn hình.
Có sẵn bộ đếm giờ cho các slide checkpoint.

## Xem online

👉 https://tai-tz.github.io/mini-hackathon-3b-tong-quan/

Vào thẳng một slide bất kỳ bằng hash, ví dụ `#slide-10`.

## Phím tắt

| Phím | Tác dụng |
|---|---|
| `←` `→` | Chuyển slide |
| `T` | Chạy / dừng đồng hồ |
| `R` | Đặt lại đồng hồ |
| `F` | Toàn màn hình |
| `Ctrl` + `P` | In ra PDF |

Bấm vào số giờ để gõ số phút bất kỳ · 🔔 bật/tắt chuông.

## Chạy local

Mở trực tiếp `index.html` bằng trình duyệt, hoặc:

```bash
python -m http.server 8000
```

rồi truy cập http://localhost:8000
